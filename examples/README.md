# Examples

Project profiles in ROSHub's format. Copy one into `~/.roshub/projects/`, or create it from the UI by importing the repo.

| File | Simulator | Robot | Status |
|---|---|---|---|
| `turtlebot3_gazebo.yaml` | Gazebo Harmonic | TurtleBot3 Burger | ✅ verified on Jazzy |
| `isaac_attach.yaml` | Isaac Sim (running separately) | any | ⚠️ template |
| `webots_ur5e.yaml` | Webots | UR5e arm | ⚠️ untested |
| `mujoco_arm.yaml` | MuJoCo | ros2_control arm | ⚠️ template |

`${WS}` stands for the workspace path; ROSHub fills it in when you import.
